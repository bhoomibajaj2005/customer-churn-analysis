# Customer Churn & Revenue Risk Analysis

This project presents an end-to-end customer churn and revenue risk analysis
using Python for data analysis and Power BI for interactive dashboards.

## Tools Used
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Power BI
- GitHub

## Project Highlights
- Customer churn behavior analysis
- Revenue-at-risk segmentation
- Interactive Power BI dashboards
